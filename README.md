# MafraqX — تطبيق توصيل المفرق–عمان

مشروع تصميم وتطوير تطبيق جوال لربط الركاب بسائقي سيارات على خط **المفرق ↔ عمان**، بنفس منطق تطبيقات أوبر وكريم وتكسي إف.

## تشغيل التطبيق

```bash
cd app
npm install
npm run dev
```

ثم افتح: **http://localhost:5173**
